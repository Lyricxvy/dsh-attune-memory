# v0.2.0 · 架构收口（Architecture Closure）

**发布定位**：不新增功能，聚焦把分散的契约收拢成单一事实源、补上安全不变量、恢复运行时断链，并建立端到端穿透测试与启动自检，让契约漂移当场可抓。

## 变更总览

### 1. 契约收口（单一事实源）
- 每个操作的 params / required / writes / handler 收敛到引擎侧单一 OPS 注册表（27 个操作），校验、分发、自检描述全部由它派生。
- 新增只读 describe 操作；插件启动时比对写操作集合，不一致则写操作 fail-closed、读不受影响。

### 2. 安全不变量
- 记忆写入新增 explicit 字段，默认 False：模型不主动声明「用户明说」，就按推断处理（置信度上限 0.7、禁 always、禁自动取代）。不可逆覆盖必须 deliberate opt-in。

### 3. 移除模型端物理删除
- 模型工具 memory_forget 移除 hard 参数，仅保留软删（可恢复）；物理删除只保留人工入口（CLI / 管理页两段式）。

### 4. 恢复三条断链
- memory_preview：修复白名单缺失导致的 KeyError。
- 兜底抽取：修复「先预览后写入」死链，新增抽取四计数（attempt / written / blocked / failed），静默失效归零。
- 管理页诊断接口：修复 /api/reads、/api/discarded 的变量误用。

### 5. 测试与自检
- 新增 27 个操作的端到端穿透测试（happy path + 非法参数），由 describe 派生。
- 反向验证：删除任一操作契约即测试变红，证明单一事实源抓得住漂移。
- 启动自检三态（ok / mismatch / unavailable），只有 ok 放行写操作。
- CI 插件测试从 6 个文件扩到 10 个，新增布局防复发闸。

## 架构决策记录
- ADR-035：引擎 OPS 单一事实源
- ADR-036：explicit 默认 False + 移除模型端 forget hard

## 兼容性
- 接口 100% 向后兼容。
- 行为对「省略 explicit 的新写入」不兼容：从默认按显式处理，改为默认按推断处理。
- 现有数据库无 schema 迁移。

## 验证
- 引擎单测 120 通过；评估场景 24/24；插件测试 10 文件全绿；布局自检 23 项通过。
