# v0.3.0 更新报告（可靠性、规模与时态 / Reliability, Scale & Time）

## 0. 文档信息

- 项目：dsh-attune-memory（DeepSeek Harness 跨会话长期记忆插件）
- 版本：v0.3.0
- 编制时间：2026-11-24
- 对应提交：tag `v0.3.0` 指向本次发布提交
- 分支：main
- 详细背景：`docs/reports/v0.3.0-work-report.md`（逐工作包的对照与证据状态）、`docs/plans/v0.3.0-implementation-plan.md`（计划与范围）

## 1. 这一版做了什么

v0.3.0 **不新增用户可见功能**，修的是"看不见的坏"：写入不够准、数据不够整、规模一上来就慢、时间维度缺位、冲突判据模糊、出问题看不出是哪一段断的。

v0.2.0 解决的是"同一份契约在五个地方各写一遍"；这一版往下一层走——把"我们以为它可靠"变成"有对照基线、有失败样例、有可复算数字"。

## 2. 用户能感觉到的变化

- **写入变严**：工位状态（"我在改这个文件"）、文件里能直接查到的、一次性安排、否定句式，不再被当成长期记忆写进去。这类内容以前会堆进库里，然后每轮抢上下文。
- **删除与修改不留半截**：物理删除要么完整消失、要么不动；`update` / `merge` 必须过和新增同一套校验，不再能绕过枚举与主体约束。
- **规模不再是平方级**：批量写入从 O(n²) 降到接近线性；检索不再"只看最近 200 条"，长期使用后旧记忆不会被无声挤出候选集。
- **记忆有了时间维度**：区分"现在成立 / 过去成立 / 一次性事件 / 不确定"，并区分"记错了"（corrected）与"事实变了"（superseded）——两种情况的追溯方式不同。
- **冲突判据变硬**：只有真正互斥的事实才取代；同一句话换个说法就地改，不再制造两条并列的记忆。极性词判断收窄到低频组合，避免中文里满地都是的"是/不是"造成误判。
- **状态可观测**：一条记忆从候选、准入、落库到被注入，每一段都有计数。出问题能回答"这条为什么没被模型看到"，而不是只能猜。

## 3. 结构性变化（自己写脚本调用引擎的要注意）

- 新增 **task scope**：同一话题下的约定只在对应任务范围内生效，不再全局限定或全局失效。
- 写入路径改成**分级准入**：先判是否值得记，再判主体、类型与作用域，最后才落库；被挡下的条目带原因进丢弃记录。
- **事务与库维护**：写入与状态变更统一在可重入事务里；库结构升到 schema v5，新增 `temporal_kind`、`invalidation`、`event_date`、`last_verified` 四列。
- **读路径只读**：查询不再顺手写库，计数与访问记录走独立更新路径，避免读操作把缓存状态搅乱。
- 新增 **四道闸**与规模基准：契约闸、场景闸、判分器闸、规模闸可以分别失败，不再"一绿全绿"。

## 4. 升级步骤

1. 无新增依赖，Python 与 Node 版本要求不变。
2. 打开旧库会自动迁移（schema v4 → v5，四个 `ALTER TABLE` 加一次数据回填）。**升级前建议先备份 `memory.db`**；迁移是幂等的，重复打开不会重复加列。
3. 重启 DeepSeek Harness（插件与引擎子进程只在启动时创建）。
4. 如果你自己写脚本直接调引擎 API：注意 `search` 的返回结构新增了时态与失效字段，`record` 类调用走只读路径后不再隐式写库。

## 5. 验证

- 引擎单测 **183 通过**（v0.2.0 为 120）。
- 五项场景评估 **24/24**。
- 插件测试 **10 个测试文件 + 契约测试**全绿（源码树与打包改名后的发布树都跑）。
- 布局自检 **23 项通过**；发布 zip 与仓库逐文件 sha256 零差异。
- CI 在 GitHub Actions 上跑同一组命令。

需要说清楚的是：**这些仍是自证**。外部基准全部标为 `UNVERIFIED`，退化题的归因有记录但没有逐题复算，结论只在"同一套数据、同一个 K"的对照下成立。

## 6. 已知限制与未做

- Raw-history RAG、MCP Server、语义（Embedding）检索、人工审核队列**不在本版**，前两项划到 v0.4.0。
- 外部基准的判分器仍依赖人工标注集，无法覆盖长尾表达。
- 代理层压缩盲区依旧：常驻层（system prompt）免疫，但按轮注入的块会被上游代理折掉，插件收不到通知。
- 版本号仍然分散在四处（`package.json`、引擎 `__version__`、zip 名、`.audit` 目录名），回退要一起退。

完整背景见 `docs/reports/v0.3.0-work-report.md`。
